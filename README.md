# Gestor de Tareas

Aplicación web para organizar tareas diarias. Permite crear, editar, eliminar y marcar tareas como completadas, además de filtrarlas y buscarlas.

Proyecto desarrollado con TypeScript y Vite.

## Instalación

### Requisitos previos
- Tener instalado Node.js
- Tener instalado pnpm. Hacerlo con el siguiente comando:

  npm install -g pnpm


### Pasos

1. Clonar o descargar este repositorio.
2. Entrar a la carpeta del proyecto:

   cd gestion-tareas

3. Instalar las dependencias:

   pnpm install

4. Iniciar el servidor de desarrollo:

   pnpm dev

5. Abrir en el navegador la URL que muestra la terminal.

## Características implementadas

### Gestión de tareas
- Crear tareas con título, descripción, categoría y prioridad.
- Editar tareas existentes reutilizando el mismo formulario.
- Eliminar tareas, con una confirmación previa antes de borrarlas.
- Marcar tareas como completadas o pendientes.
- Ver todas las tareas en una lista.

### Filtros y búsqueda
- Filtrar tareas por estado: todas, pendientes o completadas.
- Filtrar tareas por prioridad: alta, media o baja.
- Buscar tareas por título en tiempo real.
